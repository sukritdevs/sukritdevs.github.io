What the guidelines ask you to state

paraphrased from the papers

Undirected networks: Burger et al. (2023)

  • §2.2The estimation method and its settings: thresholds, regularization parameters. State them even when they are the defaults, because defaults change between package versions.
  • §2.3The number of bootstrap samples and the type of bootstrap.
  • §2.4The software and package versions, and any seeds set in the code.
  • §3.3What the edges represent, the smallest and largest edge, any minimum, maximum or cut value used when plotting, and how the layout was set.
  • §3.4Network density and the average absolute edge weight, which the picture alone cannot show.
  • alsoHow missing data were handled, the sample size after preprocessing, and the same layout and maximum edge value when comparing networks. A visual comparison alone is not enough.

Directed networks: Briganti et al.

  • algoThe structure-learning algorithm you chose, stated clearly.
  • bootReport only stable networks from bootstrapping. The authors recommend 100 to 200 bootstrap samples and say earlier empirical papers kept edges present in over 85% of networks, with direction in over 50%.
  • freqHow often each edge appeared across the bootstrap networks.
  • checkRun the other algorithm families as robustness checks, so readers can see which edge directions change between them.
  • equivGraphs in the same equivalence class cannot be told apart from the data, so arrow directions need care.

The toy adds one point beyond the papers: a layout seed is what lets a reader redraw your exact figure. Burger et al. ask for the seeds used in analysis code and for how the layout was set, and they warn that algorithms such as Fruchterman-Reingold are sensitive to small changes and that exact node placement should not be read as meaning. Cleome's Report and Export page writes a methods paragraph and an R replication script from the settings you actually used.
